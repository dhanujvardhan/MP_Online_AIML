# 🤖 RAG Chatbot — Capstone Project

A complete **Retrieval-Augmented Generation (RAG)** chatbot that answers questions
based on documents you upload (.pdf / .txt). Runs **100% locally — no API key,
no paid service, no internet dependency after the first model download.**

---

## 🏗 Architecture

```
                ┌───────────────┐
   Upload doc → │  FastAPI      │
                │  /upload      │──► extract text ──► chunk ──► embed ──► FAISS index
                └───────────────┘

                ┌───────────────┐
   Ask question │  FastAPI      │
   (chat box) → │  /chat        │──► embed query ──► search FAISS (top-k chunks)
                └───────────────┘         │
                                           ▼
                                build prompt with retrieved context
                                           │
                                           ▼
                              local LLM (flan-t5-base) generates answer
                                           │
                                           ▼
                                  answer + source docs → UI
```

**Tech stack**
| Layer | Technology |
|---|---|
| Backend API | FastAPI (Python) |
| Embeddings | `sentence-transformers` (`all-MiniLM-L6-v2`) — free, local |
| Vector store | FAISS (in-process, no external DB needed) |
| LLM (generation) | `google/flan-t5-base` via HuggingFace `transformers` — free, local |
| Frontend | Plain HTML / CSS / JavaScript chatbox |
| File parsing | `pypdf` for PDFs |

No OpenAI/Anthropic key, no cloud vector DB — everything runs on your machine
(CPU is fine; it'll just be a bit slower than GPU).

## ⚙️ Setup & Run

### 1. Backend

```bash
cd rag-chatbot/backend

# create a virtual environment (recommended)
python -m venv venv
source venv/bin/activate        # Windows: venv\Scripts\activate

# install dependencies
pip install -r requirements.txt

# run the server
uvicorn main:app --reload --port 8000
```

⏳ **First run will download two small models** from Hugging Face
(`all-MiniLM-L6-v2` ~80MB and `flan-t5-base` ~250MB). This needs internet
access once — after that, everything runs fully offline from the local cache.

You should see:
```
Starting RAG engine... this may take a minute on first run.
RAG engine ready.
INFO:     Uvicorn running on http://127.0.0.1:8000
```

### 2. Frontend

Just open `frontend/index.html` directly in your browser
(double-click it, or right-click → Open With → Browser).

That's it — no build step needed. It talks to the backend at
`http://localhost:8000`.

> If your browser blocks local file requests, instead serve it with:
> ```bash
> cd rag-chatbot/frontend
> python -m http.server 5500
> ```
> and open `http://localhost:5500`.

## 🧪 How to Use

1. Open the chatbot page.
2. Upload a `.pdf` or `.txt` file using the sidebar (drag-drop or click).
3. Wait for "✅ processed and added to the knowledge base".
4. Type a question about the document in the chat box and hit Send.
5. The bot retrieves the most relevant chunks and answers using only that
   context, and shows which source document it used.
6. Use "🗑 Clear Knowledge Base" to start fresh with new documents.

## 🔍 API Endpoints (for reference / testing with Postman)

| Method | Endpoint | Description |
|---|---|---|
| GET | `/health` | Health check |
| GET | `/status` | Count of chunks/documents currently stored |
| POST | `/upload` | Upload a file (multipart/form-data, field name `file`) |
| POST | `/chat` | Body: `{"query": "your question", "top_k": 3}` |
| POST | `/reset` | Clears the entire knowledge base |

Interactive API docs are auto-generated by FastAPI at:
`http://localhost:8000/docs`

## 📈 Possible Extensions (great for capstone "future work" section)

- Swap `flan-t5-base` for a larger local model (e.g. via `llama-cpp-python`)
  for better answer quality.
- Add conversation memory (multi-turn context).
- Support `.docx` / `.csv` ingestion.
- Add user authentication and per-user knowledge bases.
- Deploy backend on a cloud VM and host frontend on GitHub Pages / Vercel.
- Add streaming responses (token-by-token) for a more "live" chat feel.
- Replace FAISS with a persistent vector DB (Chroma, Qdrant, Pinecone) for
  multi-session, multi-user scale.

## 🐛 Troubleshooting

- **"Backend not reachable"** → make sure `uvicorn` is running on port 8000.
- **CORS error in browser console** → backend already allows all origins;
  double-check you're hitting `http://localhost:8000` (not `127.0.0.1` vs
  `localhost` mismatch causing confusion — both work here since CORS is `*`).
- **Slow first response** → the LLM model loads into memory once at server
  startup; subsequent requests are much faster.
- **Out of memory** → `flan-t5-base` needs ~1GB RAM; if your machine is
  constrained, switch `LLM_MODEL_NAME` in `rag_engine.py` to
  `"google/flan-t5-small"` (smaller, faster, slightly less accurate).
